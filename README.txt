StudioFlow — Pilates Studio Manager

HOW TO USE
1. Open index.html in a browser to try the app locally.
2. Your data is saved in that browser using localStorage.
3. Use Settings > Backup data regularly.
4. To put it online, upload this folder to a static host such as Netlify Drop, or deploy it with Vercel/GitHub.

IMPORTANT
This is a usable single-device MVP. It does not yet have a cloud database or secure multi-user login.
If you open it on another browser/device, that device will have its own data unless you restore a backup.

FEATURES
- Dashboard
- Clients and session balances
- Schedule
- POS for packages and retail
- Memberships
- Inventory
- Stock purchases automatically create expenses
- Expenses such as electricity/rent/payroll
- Finance summary
- Team
- Backup/restore
